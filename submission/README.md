# Kernel submission draft

This folder contains the recommended six-patch, one-Line/Mic-control series
and a cover-letter draft. The patches are separate `git format-patch` mail
messages for submission as a threaded series:

- `0000-cover-letter.txt` — cover-letter text addressed from Davide Gironi.
- `0001-*.patch` through `0006-*.patch` — individual kernel patches.
- `phase88-combined.patch` — the same six changes combined as one patch; use
  this instead of the six-patch series if a single mail is required.

## Kernel source and validation

The official Linux 6.18.58 source archive is in `kernel/linux-6.18.58.tar.xz`
and its extracted source is in `kernel/linux-6.18.58/`. The `/kernel/` rule
in the repository `.gitignore` excludes both from git. The six patches apply
cleanly to that source tree. `phase88-combined.patch` also applies cleanly and
reproduces the same final changes to the three driver files.

Each patch was checked with Linux 6.18.58's `scripts/checkpatch.pl
--no-tree --strict --no-signoff`. There are no whitespace/indentation issues,
errors, or warnings. Patch 0006 has one CHECK for `ICE1712_CFG_2xMPU401`, an
existing kernel macro whose spelling should not be changed in this patch.
Patch 0001 uses spaces around the shift operator as requested by checkpatch.

The patches have not been built or hardware-tested on 6.18.58. Functional
hardware testing was done on two PHASE 88 racks with 6.18.55, and the driver
was built against Debian 6.12.111. The downloaded source is a release tarball
without git history; the patch mail files have their `From:` author set to
Davide Gironi <davide.gironi@gmail.com>.

## Not ready to send

`Signed-off-by` trailer. Davide must personally confirm that he has the right
to submit the work and add his own DCO sign-off. An AI assistant must not add
a Signed-off-by line. Patch 0001 and the combined patch include
`Assisted-by: Pi:gpt-6-luna` to disclose the style-only spacing edit made
during this preparation; the kernel change itself was not generated by the
assistant.

## Before sending

1. After confirming the DCO, add `Signed-off-by: Davide Gironi
   <davide.gironi@gmail.com>` once to the combined patch, or to each of the
   six patches (preferably via `git commit -s` in the source Git repository,
   then regenerate them). The release tarball itself has no Git history.
2. Re-run `scripts/checkpatch.pl --strict` on every final patch, including
   normal sign-off checking, and review any remaining reports.
3. Verify recipients with the target tree's `scripts/get_maintainer.pl` and
   `MAINTAINERS`. Existing project notes suggest `linux-sound@vger.kernel.org`
   with Jaroslav Kysela and Takashi Iwai copied; confirm this is still correct.
4. Send as plain-text email, one patch per message in a thread under the
   cover letter (for example, with `git send-email`); do not attach patches.

The cover letter is a draft and should be checked against the final test
results and exact patch version. See
<https://docs.kernel.org/process/submitting-patches.html>.
