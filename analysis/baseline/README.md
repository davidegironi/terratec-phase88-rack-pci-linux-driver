# Sanitized baseline captures

These captures document the test machine and audio-device state used during
PHASE 88 driver investigation (Linux 6.18.55). They are retained as supporting
reproduction context; the project-level investigation and conclusions are in
[`../README.md`](../README.md).

Before adding these files to version control, machine-specific identifiers
were redacted from the captures: filesystem UUIDs, hostname/user label, network
MAC address, USB storage serial number, and PCI device serial number. Hardware
model and device information remains where useful for reproducing the test
setup.
